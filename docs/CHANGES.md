# 从原项目到 GitHub 版本

重构基于原项目中的 `main.c`、`cnf.c`、`file.c`、`sudoku.c` 和 `def.h`。保留 SAT 求解、普通 / 对角线数独、加载、生成及终端游戏的主要用途。

| 原实现的问题 | 当前处理 |
| --- | --- |
| `main.c` 直接包含其他 `.c`，头文件定义全局状态 | 独立编译各模块，公共接口放入 `include/`，状态归求解上下文所有 |
| 回溯仅切换选择变量，已传播赋值可能残留 | trail 检查点撤销整个失败分支的赋值 |
| 分支深拷贝链表，分支内存释放不完整 | 不修改公式，双监视文字传播，统一释放上下文 |
| 固定 `counter[MAX]` 且输入范围缺少检查 | 按变量数动态分配，检查文字范围和分配失败 |
| `fscanf("%s", filename)` 会改写文件名且未限制长度 | 独立的有界 token 读取器，错误通过返回值报告 |
| 空公式、空子句和异常输入缺少完整处理 | 明确区分 SAT、UNSAT 与错误；严格检查头部、计数与终止符 |
| 答案通过临时 `.res` 文件再读取，索引边界不正确 | 直接从内存模型按 `v - 1` 解码，覆盖变量 729 边界 |
| `DigHole[82]` 初始化循环会访问索引 82 | 使用长度 81 的挖洞顺序数组，边界与盘面一致 |
| 挖洞通过替换单格数字推断唯一性，遍历遗漏数字 9 | 对整盘面计数到第二个解，只有计数为 1 时保留挖洞 |
| 不可继续挖洞时可能永久循环 | 最多尝试 8 个完整盘面，未达目标明确返回失败 |
| 初始化 / 删除格子时剩余洞数容易失真 | 完成判定检查完整盘面的真实规则，不维护易失真的洞数计数 |
| `system("cls")`、绝对编译器路径与旧中文编码 | 标准 C I/O、通用 CMake、UTF-8 文档与英文终端提示 |

SAT 基础文件不再是数独运行依赖。原来的两个基础 CNF 保存在 `examples/legacy/`，用于验证旧输入兼容性；它们的子句数与新生成的显式编码不同。

旧接口未做二进制或源代码 API 兼容。CLI 增加了非交互命令，游戏行列从原来的 0–8 改为 1–9。结果文件保留 `s / v / t` 结构，增加模型结尾的 `0`，输出文件名不再被自动改写为 `.res`。

本次没有对旧程序进行可比性能基准测试，因此不声明具体加速倍数。改变存储、传播和回溯方式的目的，是减少不必要复制并确保状态可正确撤销。
